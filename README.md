# ESPHome Local Scheduler

A project for running schedules on ESPHome devices without requiring a continuous connection to Home Assistant or the internet.

This repository currently contains project scaffolding. The AOFO v0.1.0 baseline is pending recovery of the exact YAML and JavaScript used by the installed firmware. No firmware release is available.

- [Generic AOFO example](examples/aofo/README.md)
- [Verification plan](tests/README.md)
- [Changelog](CHANGELOG.md)

The `develop` branch is reserved for the generic v0.2.0 external component.
