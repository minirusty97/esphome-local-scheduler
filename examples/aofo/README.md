# Generic AOFO example

[aofo-outputs.yaml](aofo-outputs.yaml) illustrates labels for a four-outlet strip with switched USB. It contains ESPHome substitutions for use in an existing configuration. Map labels to the verified switches on your hardware revision. The file contains no pin or Tuya datapoint assignments.

The example does not include the scheduler, a daily schedule, or a complete firmware configuration. ESPHome validation and bench testing require a complete configuration for the target hardware.
